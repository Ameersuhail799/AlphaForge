# Multi-Asset Feature Research & Subset Generalization (Mission 11)

## Architecture Overview

The `src.research.multi_asset_feature_research` module provides a leakage-free, multi-asset validation framework designed to evaluate whether normalized feature subsets generalize across diverse equity symbols and market regimes.

---

## Key Configurations

1. **`ALL_32`**: Full uncurated feature matrix (32 features) generated by [`FeaturePipeline`](file:///c:/Users/AMEER%20SUHAIL/OneDrive/Desktop/projects/AlphaForge/src/features/feature_pipeline.py).
2. **`SHORTLIST_16`**: 16 normalized, relative features:
   - *Price Structure:* `GAP_PCT`, `OPEN_CLOSE_PCT`, `HIGH_LOW_PCT`, `BODY_SIZE`, `UPPER_WICK`, `LOWER_WICK`
   - *Momentum:* `ROC_12`, `RSI_14`, `PRICE_CHANGE_PCT`, `DAILY_RETURN`
   - *Volatility:* `ROLLING_STD_20`, `HIST_VOL_20`, `ATR_14`, `DAILY_RANGE_PCT`
   - *Volume Relative:* `VOLUME_RATIO`, `VOLUME_CHANGE_PCT`
3. **`NO_PRICE_LEVELS_27`**: 27 features (`ALL_32` minus raw price levels `Open`, `High`, `Low`, `Close`, `Adj Close`).
4. **`DUMMY_BASELINES`**: `majority` class classifier and `previous_day` direction predictor.

---

## Leak-Free Validation Protocol

* **Partitioning:** 85% non-test partition for cross-validation, 15% out-of-sample holdout test partition (strictly isolated).
* **Cross-Validation:** 5-fold expanding window cross-validation executed on the 85% non-test partition.
* **Scaler Isolation:** [`FeatureScaler`](file:///c:/Users/AMEER%20SUHAIL/OneDrive/Desktop/projects/AlphaForge/src/dataset/scaler.py) is fitted exclusively on fold training data (`X_train`) and applied to validation (`X_val`).
* **Models Evaluated:** `logistic_regression`, `random_forest`, `xgboost` with deterministic seeds.

## Usage

Run programmatically:
```python
from src.research.multi_asset_feature_research import run_multi_asset_feature_research

results = run_multi_asset_feature_research(
    assets=["reliance_ns", "tcs_ns", "hdfcbank_ns", "infy_ns", "icicibank_ns"],
    folds=5,
    scale=True,
)
```

Run test suite:
```powershell
python -m tests.test_multi_asset_feature_research
```
